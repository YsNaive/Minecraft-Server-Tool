# AI Agent 開發指南與專案導覽

本專案是一個基於 C# / .NET 10 開發的 Minecraft 伺服器管理工具 (`MCServerTool`)，底層基於 ImTK 框架。
本文件 (`AGENTS.md`) 為 AI Agent 參與開發與維護時的**最高指導原則**與**專案導覽**。

---

## 1. 核心開發規範

在修改或重構任何程式碼之前，你**必須**遵守以下開發規範：

### 1.1 任務探勘與討論原則
* **深度探勘為先**：在開始規劃具體的實作計畫之前，必須與使用者進行深度的討論以釐清需求與架構細節。
* **條列式討論**：與使用者討論時，請先條列式地列出所有需要討論的架構點或問題。
* **逐項深入**：接下來必須**一項一項**地深入討論，直到該項細節完全釐清並定案為止。**嚴禁將多個複雜的技術細節混雜在一起**大致帶過，以免造成架構理解上的模糊與未來重工。

### 1.2 任務追蹤與文檔維護原則
* **優先查看 `TODO.md`**：當收到新任務或指令不明確時，**必須**優先查看 `docs/Project/TODO.md`，以確認當前的開發焦點。
* **找尋技術資料的途徑**：請透過查閱 `docs/` 底下的資料夾來理解各模組的現行規範。
* **閱讀規格為先**：在修改任何模組的程式碼之前，必須先尋找並閱讀該模組相關的 Markdown 規格文件。
* **純粹的事實紀錄**：更新規格文件時，只記錄事實與當下的架構現狀。絕對不要在文檔中加入修改日誌、更新歷史或 changelog。

### 1.3 C# 開發規範
* 本專案統一使用 **.NET 10**。
* **遵循 Naming Conventions**：必須嚴格遵守 `docs/Project/NamingConventions.md` 中規定的命名與大小寫規範。
* **ImTK 封裝習慣**：避免直接呼叫 ImGui 底層 API（除非 ImTK 未封裝），應優先使用或擴充 ImTK 的 `VisualElement` 和 `Window` 架構。

---

## 2. 專案導覽

本專案直接依賴並引用 ImTK。主要的開發區域為 `MCServerTool/`。
你可以從 `docs/README.md` 開始瀏覽文檔架構。

### 1.4 ImTK Package 依賴原則
* **嚴禁修改 ImTK package 中的內容**。
* 如有一定要動到 ImTK 內核的需求，可以向使用者提出、討論，但**嚴禁擅自修改** ImTK submodule 內的任何程式碼或設定。
